# Web Studio Starter

Početna WordPress blok-tema za izradu modernih prezentacijskih web stranica.

## Sadržaj
- Uređivanje zaglavlja, navigacije, podnožja i sadržaja kroz WordPress Site Editor.
- Naslovnica s hero sekcijom, pozivima na akciju, uslugama i završnim CTA blokom.
- Predlošci za stranice, objave, arhive, popis objava i 404.
- Responzivna osnova, prilagodljivi tipografski i koloristički tokeni.
- Podrška za postavku smanjenog kretanja radi pristupačnosti.

## Instalacija u WordPress Studio
1. Preuzmite mapu themes/web-studio-starter.
2. Kopirajte je u wp-content/themes/ lokalne WordPress instalacije.
3. U administraciji otvorite Izgled → Teme i aktivirajte Web Studio Starter.
4. U Izgled → Uređivač prilagodite naziv stranice, navigaciju, boje, tekstove i sekcije.
5. Izradite stranicu Kontakt i povežite je s gumbima na naslovnici.
