# WordPress teme

Ovdje će se nalaziti vlastite WordPress teme i njihove dokumentacije.

## Standardi
- Svaka tema ima vlastiti direktorij.
- Uključiti style.css, potrebne predloške i jasne upute za instalaciju.
- Prednost dati WordPress block theme pristupu kada odgovara projektu.
- Ne vezati poslovnu logiku uz temu; funkcionalnosti pripadaju dodacima.
- Testirati responzivnost, pristupačnost, performanse i kompatibilnost s podržanom WordPress verzijom.
- Evidentirati licence svih uključenih resursa.

Prva tema još nije dodana. Najprije ćemo definirati zajednički dizajn sustav i osnovni starter.
