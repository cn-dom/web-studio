# Web Studio Blocksy Starter

Free child theme for the free Blocksy WordPress theme. It adds original Gutenberg patterns for business, stonework/trades and accommodation websites.

## Requirements
- Parent theme: Blocksy (slug: blocksy), installed from WordPress.org.
- Optional companion: Blocksy Companion (slug: blocksy-companion), installed from WordPress.org.
- WordPress block editor (Gutenberg).

This package does not include Blocksy itself, paid extensions, premium Starter Sites, third-party demo content or stock photography.

## Install manually
1. Install and activate Blocksy.
2. Optionally install Blocksy Companion from WordPress.org for the official Starter Sites library.
3. Upload this child theme ZIP and activate Web Studio Blocksy Starter.
4. Edit a page and insert a layout from the Web Studio pattern category.
5. Replace every sample text and placeholder with accurate client information.

## WordPress Studio
Use one of the JSON Blueprints in wordpress/blueprints. In WordPress Studio choose Add site, then Upload Blueprint, and select the JSON file. The Blueprint installs Blocksy, Blocksy Companion and this child theme, then creates a sample Croatian-language site.

## Included patterns
Business hero; stonework/trades hero; apartments/tourism hero; services grid; about section; project gallery; contact call to action; testimonial.

All layouts use native WordPress blocks and can be edited in Gutenberg.

## ZIP paket
Nakon spajanja promjena na main, GitHub Actions automatski izrađuje ZIP datoteku child teme. Otvori Actions → Package WordPress starter themes → zadnje uspješno pokretanje → Artifacts i preuzmi web-studio-blocksy-starter. ZIP zatim možeš instalirati u WordPressu kroz Izgled → Teme → Dodaj novu → Prenesi temu.
