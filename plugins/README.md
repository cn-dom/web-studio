# WordPress dodaci

Ovdje će se nalaziti vlastiti WordPress dodaci.

Dodatke koristiti za funkcionalnosti koje trebaju ostati dostupne i kada se promijeni tema, primjerice posebne vrste sadržaja, integracije ili poslovna pravila.

## Standardi
- Svaki dodatak ima vlastiti direktorij i README.
- Koristiti WordPress API-je i provjeriti ulazne podatke.
- Primjenjivati capability checks, nonces i sanitizaciju/escaping.
- Ne pohranjivati tajne ključeve u repozitorij.
- Navesti kompatibilne verzije WordPressa i PHP-a.
- Testirati aktivaciju, deaktivaciju i nadogradnju.
- Evidentirati licence ovisnosti.
