# Biblioteka predložaka

Ovdje će se organizirati početni dizajni i ponovljivo upotrebljivi predlošci za klijentske web stranice.

## Planirane kategorije
- Obrti i uslužne djelatnosti
- Građevina i proizvodnja
- Restorani i kafići
- Apartmani i turizam
- Saloni i osobne usluge
- Udruge i organizacije
- Profesionalne poslovne stranice

Svaki predložak treba imati:
- opis namjene i ciljane publike,
- popis stranica i sekcija,
- pregled desktop i mobilnog prikaza,
- upute za prilagodbu,
- popis dodataka i vanjskih resursa,
- evidenciju licenci.

Predlošci će biti dodavani tek nakon što se uspostavi osnovni dizajn sustav i testni WordPress starter.
