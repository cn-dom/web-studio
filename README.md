# PatriaSoul — WordPress portal

Novi, zasebni WordPress portal PatriaSoul. Ovaj repozitorij više nije Web Studio.

## Struktura
- `patriasoul-theme/` — instalabilna WordPress tema.
- `index.html` — statički pregled dizajna za GitHub Pages; nije WordPress niti zamjena za WordPress administraciju.

## Lokalno testiranje WordPress teme
1. Kopirati mapu `patriasoul-theme` u `wp-content/themes/`.
2. U WordPress administraciji otvoriti **Izgled → Teme** i aktivirati **PatriaSoul**.
3. Objaviti početne stranice i članke kroz WordPress.

Tema koristi WordPressove standardne objave, stranice, kategorije, istaknute slike i izbornike. GSAP se učitava s CDN-a samo za animacije; sadržaj i osnovni izgled ostaju dostupni i bez animacija.

## Smjer portala
**Upoznaj Hrvatsku. Čuvaj baštinu. Prenesi priču.**

Istaknute cjeline: Domovina, Hrvatska pamti, Vjera i obitelj, Kultura i znanje, Mediji i Zajednica.
