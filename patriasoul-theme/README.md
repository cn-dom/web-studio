# PatriaSoul WordPress Theme

Prilagođena WordPress tema za portal PatriaSoul.

## Instalacija
Prenesite mapu `patriasoul-theme` u `wp-content/themes/`, zatim aktivirajte temu u WordPressu.

## Priprema sadržaja
Izradite kategorije sa slugovima: `domovina`, `hrvatska-pamti`, `vjera-i-obitelj`, `kultura-i-znanje`, `mediji`. Izradite glavni izbornik i dodijelite ga lokaciji **Glavni izbornik**. Objave s istaknutim slikama automatski se prikazuju na naslovnici.

## Napomena
Početna stranica koristi prilagođeni PHP predložak. GitHub Pages prikazuje statički dizajnerski pregled iz korijenskog `index.html`; stvarno uređivanje sadržaja, korisnički računi, mediji i objave rade u instalaciji WordPressa.
