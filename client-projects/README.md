# Klijentski projekti

Klijentske web stranice vode se kao odvojeni projekti i zasebne WordPress instalacije.

## Pravila odvajanja
- Ne miješati baze podataka, medije, korisnike ni pristupne podatke različitih klijenata.
- Ne spremati produkcijske lozinke, privatne ključeve ili osobne podatke klijenata u ovaj repozitorij.
- Za svaki projekt voditi zaseban opis zahtjeva, opseg posla, korištene dodatke i licence.
- Prije većih izmjena napraviti sigurnosnu kopiju.
- Klijentski projekt mora se moći izvesti i prenijeti na kompatibilan WordPress hosting.

Ovaj direktorij zasad sadrži samo standarde. Stvarne klijentske podatke ne pohranjujemo ovdje.
